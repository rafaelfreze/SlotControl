# Password Standard — OnPlay

Todos os fluxos de criação e alteração de senha aceitam qualquer composição com no mínimo 8 caracteres, sem máximo artificial e sem obrigatoriedade de categorias.

Frontend, backend e Supabase Auth devem permanecer alinhados. Recomendações de força são apenas orientativas. Uma regra mais restritiva depende de decisão arquitetural multiproduto explícita.
